Infix to Postfix Converter
This project is a command-line utility that converts mathematical expressions from infix notation to postfix (Reverse Polish) notation.

Infix notation is the standard way of writing mathematical expressions, with operators placed between the operands (e.g., 2 + 3). Postfix notation, on the other hand, places the operators after the operands (e.g., 2 3 +). The primary purpose of this conversion is to make expression evaluation more straightforward for a computer. Postfix expressions are evaluated using a stack and eliminate the need for parentheses and complex operator precedence rules.

Features
Handles standard arithmetic operators: +, -, *, /, ^ (exponentiation).
Respects operator precedence (*, /, ^ have higher precedence than +, -).
Correctly processes nested parentheses.
Built using a stack-based algorithm.
